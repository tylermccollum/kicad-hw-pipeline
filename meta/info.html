Hardware pipeline (KiBot + Hugo)

Blank KiCad 10 project with a containerised manufacturing and documentation pipeline: KiBot outputs (schematic PDF, BOMs, iBOM, 3D renders, diffs, JLCPCB package), fabrication and assembly drawings with templated notes, and a versioned Hugo site that can be hosted locally or on GitHub Pages.

After creating the project, close it in KiCad and run hw init (Windows) or ./hw init (macOS/Linux) in the project folder. It reorganises the folder into a monorepo (hardware/, site/, firmware/, tools/); then open hardware/<name>.kicad_pro. Use hw init --flat to keep everything at the top level. See README.md.

Needs Docker Desktop, git and Python 3 (Windows, macOS or Linux).
