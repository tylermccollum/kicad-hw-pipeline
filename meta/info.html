Hardware pipeline (KiBot + Hugo)

Blank KiCad 10 project with a containerised manufacturing and documentation pipeline: KiBot outputs (schematic PDF, BOMs, iBOM, 3D renders, diffs, JLCPCB package), fabrication and assembly drawings with templated notes, and a versioned Hugo site that can be hosted locally or on GitHub Pages.

After creating the project, close it in KiCad and run make -C site init in the project folder. See README.md.

Needs docker, git, rsync, jq, zip and python3.
